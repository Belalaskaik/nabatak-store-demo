# Nabatak store design demo

A clickable design demo of [nabatak.sa](https://nabatak.sa/) built only from features that can be
published on the store's current Zid plan: theme sections, Google Tag Manager blocks, a custom page
for the «ما نباتك؟» product finder, and product content.

- Products, prices and photos: snapshot of nabatak.sa on 26 Oct 2026 (167 products).
- The cart is a demo kept in your browser; orders are placed on [nabatak.sa](https://nabatak.sa/).
- Finder recommendations are a demo until the agronomist-approved planting calendar is ready.
- Pages are marked `noindex` so the demo doesn't compete with the real store in search.
